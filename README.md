# Simmer — Recipe Finder

A responsive, single-page recipe finder built with plain HTML, CSS, and JavaScript. It uses TheMealDB's public test key (`1`), so no API key setup is needed.

## Run it

Open `index.html` in a browser. If your browser blocks API requests from local files, serve this folder with any static file server and open its local URL. There is no build step or framework.

## Features

- Search meals by name and browse by category
- Open recipe details with ingredients, measures, instructions, and an optional YouTube embed
- Surprise me with a random recipe
- Save and revisit favorites with `localStorage`
- Loading, error, and empty states, plus responsive layouts for phones
